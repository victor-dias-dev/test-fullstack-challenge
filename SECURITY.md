# Security

This repository is a local educational reference. It ships with `admin` / `admin` for Postgres, RabbitMQ, and Keycloak, and with a test player `player` / `player123`. Those credentials are for Compose on your machine. Do not expose the stack to a network you do not control, and do not connect it to real balances.

## Reporting

Open a private security advisory on GitHub if you believe you found a vulnerability in the published source. Please do not file a public issue for it.

There is no bug bounty. Fixes land like any other pull request once the report is confirmed.
