# Code of Conduct

This project is a public reference. Discussion happens in issues and pull requests.

- Critique the code and the design. Leave the person out of it.
- Assume the other person has context you do not, and ask before you accuse.
- Do not post other people's private information.
- Do not use the issue tracker for harassment, spam, or anything unrelated to the repository.

Maintainers may edit or hide comments that break these rules, and may block repeat offenders. Report a problem through a GitHub security advisory or by contacting the repository owner.
